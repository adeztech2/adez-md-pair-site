# ADEZ MD - Pair Code Generator

A beautiful, professional pair code generator for ADEZ MD WhatsApp Bot.

## Features
- 🔒 Secure pair code generation
- 📱 QR Code support
- 📋 Copy buttons
- 🎨 Modern dark theme design
- 📱 Mobile responsive

## How to Use
1. Enter your WhatsApp number
2. Click "Get Pair Code"
3. Copy the code
4. Open WhatsApp > Settings > Linked Devices
5. Tap "Link with Phone Number"
6. Enter the code
